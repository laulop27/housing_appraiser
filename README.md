# 🏠 Housing Appraiser - Real Estate Valuation & Modeling

An interactive end-to-end data science project built in **R** to clean, analyze, and model real estate data for housing price appraisal. 

This repository contains the complete analytical pipeline—from raw data preprocessing to predictive modeling—along with an interactive Shiny web application for live price estimates.
